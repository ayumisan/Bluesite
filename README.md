# 福島ブルーベリーファーム ホームページ（プロトタイプ）

埼玉県嵐山町の農園「福島ブルーベリーファーム」の仮ホームページです。
サーバーもデータベースも使わない、静的なページです。デザインは **B案「朝摘みの推しベリー」** です。

園の主な名前は **福島ブルーベリーファーム** です。
「ブルーミム」は未確定の愛称案で、フッターにだけ出しています。

## 見方

このフォルダで、次を実行します。

```bash
python3 -m http.server 8080
```

ブラウザで <http://localhost:8080> を開きます。止めるときは Ctrl+C です。
`index.html` を直接開いても表示できます。

文字は、ネットにつながっているとき [Google Fonts](https://fonts.google.com/) の M PLUS Rounded 1c と Nunito を使います。オフラインのときは、端末のゴシック体に落ちます。

## 文章を直す

`index.html` の日本語を、そのまま書き換えてください。

| コーナー | 場所 |
| --- | --- |
| 先頭 | `id="top"` |
| いま旬の果実 | `id="seasons"` |
| 推しブルーベリー | `id="oshi"` |
| 季節の果実カレンダー | `id="calendar"` |
| テーマソング | `id="song"` |
| 出荷ログ | `id="log"` |
| 販売場所・農園のこと | `id="shop"` |
| フッター | `footer` |

初期表示は秋（栗の出荷中）です。季節の切り替えは `js/main.js` です。

## 色とフォントを直す

`css/styles.css` の先頭、`:root { ... }` が色と書体の置き場です。
B案の変数は次のとおりです。

| 変数 | 色 | 役割 |
| --- | --- | --- |
| `--color-logo-navy` | `#0A3556` | 本文・見出し |
| `--color-white` | `#FFFFFF` | ページの地 |
| `--color-mist` | `#EEF3F8` | セクションの地 |
| `--color-berry` | `#4A2D7A` | 主ボタン・リンク |
| `--color-young-leaf` | `#9CCB5B` | 装飾だけ（文字には使わない） |
| `--color-leaf-text` | `#3E6B22` | 緑の文字 |
| `--color-chestnut` | `#8A5A34` | 栗・出荷中 |
| `--font-heading` `--font-body` | M PLUS Rounded 1c | 和文 |
| `--font-latin` | Nunito | 欧文・数字 |

## 画像を直す

| ファイル | 中身 |
| --- | --- |
| `assets/logo.svg` | 丸いロゴ。本番の SVG / PNG が届いたら、このファイルを差し替えるか、`index.html` の `src` を変えてください。 |
| `assets/hero.svg` | 先頭のイラスト。農園の写真に替えるときは、同じ場所に画像を置き、`index.html` の `src` と `alt` を変えてください。 |

写真に替えたあとも、近くの「写真イメージ」の文言は外してください。
絵も写真も、大きすぎないファイルにしてください。

## まだ入れていないこと

破線の `【要確認】` は未確定です。それらしい数字や住所を作って埋めないでください。

未確定なのは、住所、営業時間、摘み取り料金、栗・いちじくの価格と時期、駐車場、電話、最寄り駅（東武東上線 武蔵嵐山駅は目安）、品種名、味の数値、テーマソングの音源、出荷ログの写真です。
カレンダーの色バーは、一般的な月の並びの見本です。
